Portfolio design kit · v1

Papel cálido, líneas finas y un [[solo resaltador]].

Todo el lenguaje visual del portfolio en una hoja: colores, tipografía, texturas, animaciones y componentes. Cada pieza está viva en esta página y el CSS que la produce está en kit/, listo para copiar a un proyecto nuevo.

Cómo reutilizarlo Repo en GitHub ↗

01 · Principios

La profundidad sale de las [[líneas]], no de las sombras.

Una superficie de papel cálido, estructura hecha con hairlines de 1px, una serif editorial para los títulos y el amarillo resaltador como único color fuerte. El modo oscuro es su propia escala, no una inversión.

Color

El amarillo ocupa menos del ~5% de cualquier pantalla: el marcador de los títulos, el botón primario, la selección y los estados activos.

Estructura

Radios casi cuadrados (2px). Las tarjetas no tienen sombra. Las cajas vecinas comparten borde, así una grilla se lee como un solo dibujo de líneas.

Motion

Corto, con easing y siempre como respuesta a algo: 200ms para hovers y 700ms para lo que entra en pantalla. Todo tiene versión reduced motion.

Escritura

  • Sin em dashes ni divisores punteados: dos puntos, paréntesis, puntos.
  • → para rangos de fechas.
  • Emojis como acento: máximo uno por bloque, solo en etiquetas.

Tokens para [[claro y oscuro]].

Clic en una muestra para copiar var(--token). La muestra refleja el tema activo; los dos valores están abajo. En los tokens de texto, el badge muestra el contraste real contra --surface-bg en el tema actual.

07 · Reduced motion y accesibilidad

Nada se mueve [[sin permiso]].

reduced-motion.css se importa al final y neutraliza cada animación. Los scripts también leen prefers-reduced-motion. Pruébalo en DevTools → Rendering → Emulate CSS prefers-reduced-motion.

ComportamientoCon reduced motion
Reveal, entrada del heroVisible de inmediato
ResaltadorMarcador estático
text-in, ping, dot-grid, marqueeSin animación
Border beamOculto
TimelineDibujado completo
Cursor, parallaxDesactivados
Cambio de temaInstantáneo
Corner box en hoverSe mantiene (no es movimiento)
  • Todos los tokens de texto pasan WCAG AA (4.5:1) sobre su superficie. --text-disabled es el gris más claro que todavía pasa.
  • Sobre el amarillo el texto siempre es oscuro (#222220), también en modo oscuro.
  • El foco visible es un outline de 2px en --text-link con offset de 2px.
  • El cursor nativo nunca se oculta; el personalizado solo lo decora y solo en punteros finos.
  • Las animaciones de más de 5 segundos con contenido llevan botón de pausa visible (WCAG 2.2.2).

08 · Cómo reutilizar

De esta hoja a un [[proyecto nuevo]].

Copia la carpeta kit/ a tu proyecto y elige una de las dos rutas.

A · HTML / CSS puro

<!-- <head> -->
<script>
  // theme before first paint + enables the .js-only animations
  (() => {
    let saved = null;
    try { saved = localStorage.getItem('theme'); } catch {}
    const dark = saved ? saved === 'dark' : matchMedia('(prefers-color-scheme: dark)').matches;
    document.documentElement.dataset.theme = dark ? 'dark' : 'light';
    document.documentElement.classList.add('js');
  })();
</script>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Geist+Mono:wght@100..900&family=Inter:opsz,wght@14..32,100..900&family=Newsreader:ital,opsz,wght@0,6..72,200..800;1,6..72,200..800&display=swap" />

Para cambiar la marca

  • Cambia --highlight y --cta en tokens.css: el resto del sistema es neutro.
  • Ajusta --surface-bg para mover la temperatura del papel; mantén --line-structure unos 3 pasos más oscuro.
  • Vuelve a revisar el contraste de --text-disabled: es el que está más al límite.
  • Escribe los títulos con [[...]] y un data-highlight para tener el resaltador.
