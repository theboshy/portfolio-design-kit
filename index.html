Portfolio design kit · v1

Warm paper, hairlines and [[one highlighter]].

The whole visual language of the portfolio on one sheet: colors, type, textures, motion and components. Every piece is live on this page, and the CSS behind it lives in kit/, ready to copy into a new project.

01 · Principles

Depth comes from [[lines]], not shadows.

A warm paper surface, structure drawn with 1px hairlines, an editorial serif for headings and the yellow highlighter as the only loud color. Dark mode is its own set of steps, not an inversion.

Color

Yellow stays under ~5% of any screen: the heading marker, the primary button, selection and active states.

Structure

Almost square radii (2px). Cards have no shadow. Adjacent boxes share their border, so a grid reads as one continuous line drawing.

Motion

Short, eased and always a response to something: 200ms for hovers, 700ms for things entering the viewport. Everything has a reduced motion fallback.

Writing

  • No em dashes and no dashed dividers: colons, parentheses, periods.
  • → for date ranges.
  • Emojis are accents: at most one per block, only in labels.

07 · Reduced motion and accessibility

Nothing moves [[without permission]].

reduced-motion.css is imported last and neutralizes every animation. The scripts also read prefers-reduced-motion. Try it in DevTools → Rendering → Emulate CSS prefers-reduced-motion.

BehaviorWith reduced motion
Reveal, hero entranceShown immediately
HighlighterStatic marker
text-in, ping, dot-grid, marqueeNo animation
Border beamHidden
TimelineFully drawn
Cursor, parallaxDisabled
Theme switchInstant
Corner box hoverKept (not motion)
  • Every text token passes WCAG AA (4.5:1) on its surface. --text-disabled is the lightest gray that still passes.
  • Text on the yellow is always dark (#222220), in dark mode too.
  • Focus is a 2px --text-link outline with a 2px offset.
  • The native cursor is never hidden; the custom one only decorates it, and only on fine pointers.
  • Content animations longer than five seconds get a visible pause button (WCAG 2.2.2).

08 · How to reuse

From this sheet to a [[new project]].

Copy the kit/ folder into your project and pick one of the two routes.

A · Plain HTML / CSS

<!-- <head> -->
<script>
  // theme before first paint + enables the .js-only animations
  (() => {
    let saved = null;
    try { saved = localStorage.getItem('theme'); } catch {}
    const dark = saved ? saved === 'dark' : matchMedia('(prefers-color-scheme: dark)').matches;
    document.documentElement.dataset.theme = dark ? 'dark' : 'light';
    document.documentElement.classList.add('js');
  })();
</script>

Rebranding

  • Change --highlight and --cta in tokens.css: the rest of the system is neutral.
  • Adjust --surface-bg to change the paper's warmth; keep --line-structure about 3 steps darker.
  • Recheck the contrast of --text-disabled: it is the closest to the limit.
  • Write headings with [[...]] and data-highlight to get the highlighter.
